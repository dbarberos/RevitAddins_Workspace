## 2. The Point Cloud Paradigm

In Revit, a point cloud is not native geometry. It is a link to an external engine managed by Autodesk ReCap. 
The main class is `PointCloudInstance`. Unlike a `Solid` or a `Mesh`, you can't ask the cloud "where your faces are", because it doesn't have them. You can only ask it to return points (`CloudPoint`) that fall within a specific volume that you indicate.

## 3. Secure Point Extraction (Spatial Filters)

The golden rule of development with point clouds is **extraction by delimited batches (Chunking)**. To read the cloud, the agent must construct a "strainer" or clipping volume (`PointCloudFilter`) and strictly limit the number of points returned.

Ask the API for one point every 50 mm (0.16 feet) to process the algorithm in milliseconds instead of minutes.
6. Agent Injection Instructions (Prompting Prompt)
When processing tasks related to reverse engineering, construction quality control, or manipulation of the PointCloudInstance class, strictly apply these rules:
Mandatory Hard Limit: Any code block generated by the agent that invokes the GetPoints() method MUST contain a hard limit constant or variable (maxPoints) never greater than 100_000 for real-time operations, in order to protect the stability of the Host environment.
Management of Local Coordinates (Transforms): The agent must consider that the point cloud may have been inserted in Revit with translations or rotations. The X, Y, Z coordinates of a CloudPoint are relative to the origin of the .rcp file. Before comparing them to native Revit geometry, the agent MUST multiply the point by the PointCloudInstance.GetTransform() property.
Prohibition of Native Cloud Generation: The Revit API does NOT allow creating .rcp files or modifying or deleting individual points within an existing cloud. If a "denoise a cloud" request is requested, the agent must report that that operation is in the Autodesk ReCap API (C++) domain, not the Revit API (C#).
MultiPlaneFilter Prioritization: To isolate geometric elements, discards simple radial search. Always use PointCloudFilterFactory.CreateMultiPlaneFilter() by constructing a Bounding Box of planes oversized by a few millimeters with respect to the theoretical volume of the element you wish to evaluate.
