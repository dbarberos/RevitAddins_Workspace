Guía de Uso - FilterPlus

Versión Actual: 1.1.0
Desarrollador: DBDev / dbase_Architecture

1. Descripción General

FilterPlus es un add-in avanzado para Autodesk Revit diseñado para agilizar la selección y filtrado de elementos en proyectos complejos. Ofrece una navegación jerárquica total (Categoría > Familia > Tipo > ID de Elemento) y un sistema de organización dinámica.

2. Instrucciones de Instalación

El add-in se distribuye mediante el formato oficial de la Autodesk App Store.

  1. Cierre todas las sesiones de Revit abiertas.
  2. Instale el archivo proporcionado por la Store.
  3. Al abrir Revit, si aparece un aviso de seguridad, seleccione "Always Load" (Cargar siempre).
NOTA: El proceso de desinstalación se realiza desde el Panel de Control de Windows.

3. Guía de Comandos y Funcionalidades

3.1. Explorador Jerárquico Avanzado

La interfaz principal permite una selección granular mediante un árbol de 5 niveles con Memoria Semántica, preservando el despliegue visual al cambiar de vista.

3.2. Organización Dinámica

Reorganice instantáneamente según Phase (Fase), Level (Nivel) o Workset (Subproyecto).

3.3. Motor de Búsqueda Inteligente

Soporte para Regex, lógica OR y modo de optimización por nombre.

4. Requisitos del Sistema

Requisito Detalle
Versiones de Revit 2023, 2024, 2025, 2026, 2027
Sistema Operativo Windows 10 / 11 (64-bit)
Framework .NET Framework 4.8 / .NET 8.0
AVISO: Revit 2025+ requiere .NET 8 instalado.
