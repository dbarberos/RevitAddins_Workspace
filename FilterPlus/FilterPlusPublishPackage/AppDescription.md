# FilterPlus - App Store Description

## Elevate Your Revit Selection Experience
**FilterPlus** is the ultimate selection and filtering engine for Autodesk® Revit®, meticulously engineered to handle the complexity of large-scale architectural, engineering, and construction projects. 

### Key Features:
- **Comprehensive 5-Level Hierarchy**: Navigate your project with unprecedented depth. Drill down from Categories to Families, Types, and individual Element IDs in a single, intuitive interface.
- **Dynamic Project Organization**: Re-order your selection tree on the fly. Group elements by **Phase**, **Level**, or **Workset** with a single click, allowing you to visualize and manage project data exactly how you need it.
- **Semantic Depth Memory**: Focus on what matters. FilterPlus remembers which branches you’ve expanded, even when you change the sorting criteria, eliminating the frustration of re-navigating complex trees.
- **Advanced Search Engine with Regex**: Powerful search capabilities including support for Regular Expressions (Regex), logical OR operations to accumulate multiple search results, and a "Name-Only" filter for maximum performance in massive models.
- **Seamless Multi-Selection**: Intelligent checkboxes handle parent-child relationships automatically, providing clear visual feedback for partial and full selections.
- **Production-Ready Performance**: Optimized for speed and stability with WPF virtualization and thread-safe Revit API interaction.

### Workflow Benefits:
- **Save Hours of Manual Selection**: Replace the cumbersome built-in Revit filter with a modern, hierarchical browser.
- **Clean Project Management**: Identify misplaced elements quickly by sorting by phase or workset.
- **Collaborative Efficiency**: Perfect for team environments where workset organization is critical.
- **Minimalist Design**: A sleek, dark-mode-ready interface with high-resolution vector icons that integrates perfectly into your 1080p or 4K workspace.

### System Requirements:
- **Revit Compatibility**: 2023, 2024, 2025, 2026, and 2027.
- **Operating System**: Windows 10 or Windows 11 (64-bit).
- **Framework**: .NET Framework 4.8 for older versions and .NET 8.0 for Revit 2025+.
