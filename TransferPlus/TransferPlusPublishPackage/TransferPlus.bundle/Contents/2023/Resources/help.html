TransferPlus

Version 1.3.0   Add-in ID (GUID): D1981E8C-1951-45C0-B24C-CA821B7288D2

1. Overview

TransferPlus is an enterprise-grade multi-model asset transfer and management solution for Autodesk Revit. Designed to overcome the limitations of Revit's native Transfer Project Standards tool, TransferPlus enables granular, asynchronous transferring of project standards, loadable/system families, 2D/3D views (plans, sections, elevations, callouts, drafting views, 3D views), sheets, schedules, legends, and model geometry between active documents, linked models, local directories, Autodesk Docs (ACC/BIM360), Azure Blob Storage, and AWS S3 cloud buckets.

2. Requirements and Compatibility

Compatibility: Supported on 64-bit Windows across Autodesk Revit 2023, 2024, 2025, 2026, and 2027.
  • Platform: .NET Framework 4.8 (Revit 2023–2024) / .NET 8 (Revit 2025–2027).
  • Host Application: Autodesk Revit 2023, 2024, 2025, 2026, 2027 (Win64).

3. Installation & Uninstallation

The installer that ran when you downloaded this plug-in from the Autodesk App Store has already installed the plug-in. You may need to restart the Autodesk product to activate the plug-in.

To uninstall this plug-in, exit the Autodesk product if you are currently running it, simply rerun the installer by downloading it again from the Autodesk App Store, and select the 'Uninstall' button, or you can uninstall it from 'Control Panel\Programs\Programs and Features' (Windows 10/11), just as you would uninstall any other application from your system.

4. Commands and Features Guide

4.1. Ribbon Panel Integration

By default, following Autodesk App Store single-command guidelines, the TransferPlus ribbon panel is placed under Revit's native Add-Ins (Complementos) tab.

Through the Settings (Gear Icon) dialog in TransferPlus, users can configure ribbon placement:

  • Add-Ins Tab (Default): Places the button under the standard Add-Ins tab.
  • Revit Manage Tab: Integrates into the Manage (Gestionar) tab within the Settings (Configuración) panel, immediately to the right of Additional Settings (Configuración adicional).
  • Custom Tab: Allows specifying a custom user-defined ribbon tab name.

5. Comprehensive Usage Guide

5.1. Target Document Selection (Transfer to:)

  • Multi-Model Selection: Check one or multiple destination documents simultaneously.
  • Open & Linked Models: Operates across active project files and loaded link instances.
  • Status Count: Live indicator showing total checked target models.

5.2. Hierarchical Asset Explorer (What:)

  • Families: Loadable families with real-time thumbnail previews and system families.
  • Views: Floor Plans, Ceiling Plans, Structural Plans, Sections, Elevations, Drafting Views, 3D Views, and Callouts.
  • Sheets: Titleblocks, sheets, and placed viewports.
  • Schedules & Legends: Single/multi-category schedules and component legends.
  • Project Standards: Line styles, materials, fill patterns, filters, object styles, text/dimension styles, and phases.

5.3. Conflict Resolution (On Duplicates:)

  • Keep Original: Skips existing elements, avoiding duplicates in target models.
  • Abort Transaction: Safely aborts and rolls back the operation if conflicts occur.
  • Append Suffix: Appends custom suffixes (e.g. _Copy) to transferred names.
  • PowerRename: Real-time regex pattern find/replace, prefixes, suffixes, and numbering.

5.4. View & Geometry Rules (On Views & Geometry:)

  • Accept on all Dialogs: Automatic suppression of non-fatal Revit warnings.
  • Transfer Sheet with Views: Discovers and copies all placed views alongside sheets.
  • Use Legend/Schedule if Exists: Re-references existing schedules without duplicates.
  • Transfer Callouts & Sections: Preserves callout bounds and section cut planes.
  • Transfer View Elements: Copies 2D annotations and 3D model geometry within views.
  • Force Level in Level Base Views: Preserves level associations across distinct model elevations.

5.5. Coordinate Transformations (Transform By:)

  • None (Origin to Origin): Maps $(0,0,0)$ Internal Origins directly.
  • Link (WYSIWYG): Aligns elements to their visual link instance placement.
  • Shared Coordinates: Computes differential survey point and shared coordinate matrices.

5.6. Cloud & External Family Providers

  • Local Folders: Direct .rfa directory loading.
  • Autodesk Docs / ACC: Cloud BIM 360 project integration.
  • Azure Blob Storage: Private cloud storage containers.
  • AWS S3: Scalable S3 family buckets.

5.7. Family Details & Metadata Inspection

  • Real-time Thumbnail Preview: Dynamic 128x128 pixel visual preview extracted asynchronously.
  • Metadata Inspection: Full name, active type, category, and host classification.
  • File Size (File size): Formatted size in KB or MB across local and cloud sources.
  • Last Modified (Last modified): Formatted date timestamp (yyyy-MM-dd).
  • Single-Line Trimming: Ellipsis truncation and tooltips ensure clean display without clipping.

5.8. CAD Details & 2D Drafting Views Transfer Mode

  • Five Dedicated Origins: Supports CAD Formats (DWG, DXF, DGN), Drafting Views, Detail Views/Callouts, Detail Groups, and Detail Items.
  • Real-time 2D Vector Previews: Dynamic 200x200 vector previews generated via scratch drafting views and native ImageExportOptions.
  • Title Block & Family Dynamic Rendering: In-memory EditFamily and ViewSheet generation for responsive thumbnail previews.
  • Smart Zoom-to-Extents Framing: Auto-crop with adaptive margins for small annotations and tags.
  • Middle Column Horizontal Scrollbar: Dedicated scrolling for long names while keeping checkboxes and count columns fixed.
  • Cross-Model CAD Transfer Engine:
    • Dedicated Drafting Views: Every transferred CAD instance (ImportInstance), model detail view, and 2D annotation is instantiated in its own dedicated ViewDrafting in destination documents, preserving annotation scale.
    • Sheet Hierarchy Bypass: Under Sort by Sheet, only selected child CAD/detail elements are transferred into Drafting Views; parent ViewSheet replication is strictly bypassed in CAD mode.
    • In-Memory Detail Component Loading: 2D Detail Component families (OST_DetailComponents) have their pure definitions loaded via in-memory EditFamily -> LoadFamily without creating placeholder graphics.
    • On Duplicates Compliance: Pre-flight check aborts on duplicate collisions under Abort Transaction, skips existing elements under Keep Original, and automatically appends suffixes (e.g. _Copy) under Append Suffix.
  • PowerRename Palette Integration & Chained Iterations: Full feature parity between Family Mode and CAD Mode with multi-stage chained regex matching and renamed CAD file export/download.
  • Leaf-Only CAD Deletion & Safety Confirmation: Deletion is strictly confined to lowest-level CAD/detail elements (links, imports, components). Parent Sheets and Views are never deleted and remain in the project for future reuse. Includes a hierarchical preview confirmation dialog.

6. Version History (Changelog)

v1.3.0

  • Cross-Model CAD Transfer Engine: Complete multi-document transfer architecture for CAD Mode (IsCadDetailsManagerActive), handling native Drafting Views, model detail views/callouts, CAD import instances, detail components, and isolated annotations.
  • Dedicated ViewDrafting Generation: Each transferred CAD instance, model detail view, and 2D annotation is automatically instantiated in its own dedicated ViewDrafting in target models, preserving scale and preventing view corruption.
  • In-Memory Detail Component Loading: 2D Detail Component families (OST_DetailComponents) are loaded directly into the destination model's database using EditFamily -> LoadFamily in memory without creating placeholder graphical elements.
  • Pre-Flight Duplicate Conflict Validation: Pre-flight inspection for AbortTransaction in CAD mode that validates destination view and family names before opening transactions, notifying the user via a descriptive TaskDialog.
  • PowerRename Chaining & Iterative Modification: Enhanced regex replacement matching against working names, enabling multi-stage iterative renaming without losing prior edits.
  • Renamed CAD Download & Export Pipeline: Full integration between the PowerRename palette and CAD export/download workflows, ensuring downloaded CAD files and exported .rfa detail families reflect custom renamed titles.
  • Sheet Replication Isolation: In CAD Mode under Sort by Sheet, parent ViewSheet replication is strictly bypassed; only child detail elements are transferred into dedicated drafting views.
  • Provider Architecture Harmonization: Updated ICadProvider and all implementations to honor keepOriginal and suffix policies.
  • CAD Mode Rename Palette Empty Selection: Resolved an issue where opening the Rename palette in CAD mode showed an empty list due to family-only collection filtering.
  • 2D Detail View Direct Copy Failure: Replaced direct view copying of model detail views with automated 2D annotation extraction and placement into dedicated ViewDrafting containers.
  • Collision-Resistant View Naming: Implemented iterative collision resolution (_Copy_1, _Copy_2) to prevent Revit native ArgumentException crashes when duplicate view names occur in target models.

v1.2.0

  • CAD Details & 2D Drafting Mode: Dedicated transfer mode for CAD files (DWG, DXF, DGN), drafting views, detail views/callouts, detail groups, and detail component items.
  • Dynamic 2D Vector Previews: In-memory vector preview generation using scratch drafting views, native Revit ImageExportOptions, and automated transaction rollbacks.
  • Title Block & Family Dynamic Rendering: Dynamic preview rendering for title blocks and family types using in-memory EditFamily and ViewSheet generation.
  • Auto-Crop & Zoom-to-Extents Framing: Automatic bounding box framing and margin calculations for small annotation elements, tags, and drafting items.
  • Middle Column Horizontal Scrolling: Dedicated horizontal scrollbar in the asset tree allowing unconstrained reading of long family/view names while keeping checkboxes and element count badges stationary.
  • Leaf-Only CAD Deletion with Hierarchical Confirmation Dialog: Interactive safety confirmation window before deleting CAD details from active models. Displays the hierarchy with clear visual indicators that parent Sheets and Views are preserved while only the selected leaf CAD/detail elements are deleted.
  • Ribbon Placement on Add-Ins Tab (Default): Aligned with Autodesk App Store single-command guidelines by placing the TransferPlus ribbon panel on Revit's native Add-Ins (Complementos) tab by default.
  • Revit Manage Tab Placement (Settings Group): Option to insert the TransferPlus button directly into the native Settings (Configuración) panel of the Manage tab, immediately to the right of Additional Settings.
  • Configuration Window Tab Options: Updated Tab Option selection card with clear choices: Add-Ins tab (default), Revit Manage tab, and Custom tab name.
  • Parent Sheet & View Deletion Prevention in CAD Mode: Fixed an issue where tri-state checkbox bubbling or parent node resolution in Sort by Sheet mode could cause parent ViewSheet or View containers to be deleted along with CAD details. Deletion is now strictly confined to leaf elements.
  • XML Settings Deserialization Resilience: Resolved startup deserialization errors caused by legacy DBDevDefault settings. Seamless backwards-compatible auto-upgrade to Add-Ins default with non-blocking error handling.
