# Final Steps for Publishing TransferPlus v1.0.0 to Autodesk App Store

Follow these steps to submit the **TransferPlus** add-in to the Autodesk App Store Developer Portal:

---

## 1. Review Assets and Descriptions
- **Screenshots**: Ensure that at least **4 high-quality screenshots** (1280x800 px) illustrating the main features (Asset explorer, Multi-document transfer, PowerRename, Coordinate transformations) are ready in the store submission.
- **Description**: Open `AppDescription.md` and copy the text into the "Detailed Description" field on the store portal.
- **Publisher Profile & Website**: Use the data provided in `WebsiteInfo.txt`:
  - **Publisher Name**: `DBDev_dbarberos`
  - **Company**: `DBDev Solutions`
  - **Website URL**: `https://dbdev-dbarberos.github.io`
  - **Privacy Policy URL**: `https://dbdev-dbarberos.github.io/PrivacyPolicy/`
  - **Support Email**: `dbarberos@outlook.com`

---

## 2. Package Deliverable
The compressed bundle package can be generated at any time using the automated script:
```powershell
.\.agents\skills\revit-appstore-bundle\scripts\build-bundle.ps1 -AppName "TransferPlus" -Version "1.0.0" -ProjectDir ".\TransferPlus"
```
The resulting deliverable will be located at:
* **`TransferPlus\TransferPlusPublishPackage\TransferPlus.bundle.zip`** (and `TransferPlus\Deploy\TransferPlus_v1.0.0.zip`).

---

## 3. Uploading to Autodesk App Store
1. Log in to the [Autodesk App Store Publisher Center](https://apps.autodesk.com/MyApps).
2. Create a new application submission for **Revit**.
3. In the **Package / Binary** section:
   - Upload `TransferPlus.bundle.zip`.
4. In the **Compatibility** section:
   - Check all compatible versions: **2023, 2024, 2025, 2026, 2027** (Win64).
5. In the **Store Listing / Details** section:
   - Paste the contents of `AppDescription.md`.
   - Fill in Support Email (`dbarberos@outlook.com`) and Privacy Policy URL (`https://dbdev-dbarberos.github.io/PrivacyPolicy/`).
6. Click **Submit for Review**.

---

## 4. Local Installation Verification (Sanity Check)
Before submitting, test the bundle locally:
1. Copy the generated folder `TransferPlus.bundle` to `%AppData%\Autodesk\ApplicationPlugins\`.
2. Launch Revit (2023–2027).
3. Verify that the **DBDev** tab appears in the ribbon, clicking **TransferPlus** launches the window without missing assembly errors, and assets transfer smoothly.
4. Delete the test bundle from `%AppData%\Autodesk\ApplicationPlugins\` when finished.
