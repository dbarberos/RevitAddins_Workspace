TransferPlus

Version 1.1.0   Add-in ID (GUID): D1981E8C-1951-45C0-B24C-CA821B7288D2

1. Overview

TransferPlus is an enterprise-grade multi-model asset transfer and management solution for Autodesk Revit. Designed to overcome the limitations of Revit's native Transfer Project Standards tool, TransferPlus enables granular, asynchronous transferring of project standards, loadable/system families, 2D/3D views (plans, sections, elevations, callouts, drafting views, 3D views), sheets, schedules, legends, and model geometry between active documents, linked models, local directories, Autodesk Docs (ACC/BIM360), Azure Blob Storage, and AWS S3 cloud buckets.

2. Requirements and Compatibility

Compatibility: Supported on 64-bit Windows across Autodesk Revit 2023, 2024, 2025, 2026, and 2027.
  • Platform: .NET Framework 4.8 (Revit 2023–2024) / .NET 8 (Revit 2025–2027).
  • Host Application: Autodesk Revit 2023, 2024, 2025, 2026, 2027 (Win64).

3. Installation & Uninstallation

The installer that ran when you downloaded this plug-in from the Autodesk App Store has already installed the plug-in. You may need to restart the Autodesk product to activate the plug-in.

To uninstall this plug-in, exit the Autodesk product if you are currently running it, simply rerun the installer by downloading it again from the Autodesk App Store, and select the 'Uninstall' button, or you can uninstall it from 'Control Panel\Programs\Programs and Features' (Windows 10/11), just as you would uninstall any other application from your system.

5. Comprehensive Usage Guide

5.1. Target Document Selection (Transfer to:)

  • Multi-Model Selection: Check one or multiple destination documents simultaneously.
  • Open & Linked Models: Operates across active project files and loaded link instances.
  • Status Count: Live indicator showing total checked target models.

5.2. Hierarchical Asset Explorer (What:)

  • Families: Loadable families with real-time thumbnail previews and system families.
  • Views: Floor Plans, Ceiling Plans, Structural Plans, Sections, Elevations, Drafting Views, 3D Views, and Callouts.
  • Sheets: Titleblocks, sheets, and placed viewports.
  • Schedules & Legends: Single/multi-category schedules and component legends.
  • Project Standards: Line styles, materials, fill patterns, filters, object styles, text/dimension styles, and phases.

5.3. Conflict Resolution (On Duplicates:)

  • Keep Original: Skips existing elements, avoiding duplicates in target models.
  • Abort Transaction: Safely aborts and rolls back the operation if conflicts occur.
  • Append Suffix: Appends custom suffixes (e.g. _Copy) to transferred names.
  • PowerRename: Real-time regex pattern find/replace, prefixes, suffixes, and numbering.

5.4. View & Geometry Rules (On Views & Geometry:)

  • Accept on all Dialogs: Automatic suppression of non-fatal Revit warnings.
  • Transfer Sheet with Views: Discovers and copies all placed views alongside sheets.
  • Use Legend/Schedule if Exists: Re-references existing schedules without duplicates.
  • Transfer Callouts & Sections: Preserves callout bounds and section cut planes.
  • Transfer View Elements: Copies 2D annotations and 3D model geometry within views.
  • Force Level in Level Base Views: Preserves level associations across distinct model elevations.

5.5. Coordinate Transformations (Transform By:)

  • None (Origin to Origin): Maps $(0,0,0)$ Internal Origins directly.
  • Link (WYSIWYG): Aligns elements to their visual link instance placement.
  • Shared Coordinates: Computes differential survey point and shared coordinate matrices.

5.6. Cloud & External Family Providers

  • Local Folders: Direct .rfa directory loading.
  • Autodesk Docs / ACC: Cloud BIM 360 project integration.
  • Azure Blob Storage: Private cloud storage containers.
  • AWS S3: Scalable S3 family buckets.

5.7. Family Details & Metadata Inspection

  • Real-time Thumbnail Preview: Dynamic 128x128 pixel visual preview extracted asynchronously.
  • Metadata Inspection: Full name, active type, category, and host classification.
  • File Size (File size): Formatted size in KB or MB across local and cloud sources.
  • Last Modified (Last modified): Formatted date timestamp (yyyy-MM-dd).
  • Single-Line Trimming: Ellipsis truncation and tooltips ensure clean display without clipping.
