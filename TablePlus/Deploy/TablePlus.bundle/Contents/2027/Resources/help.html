TablePlus

Version 1.0.0   Add-in ID (GUID): C9281744-8B1A-4C23-9D01-B719E022F3AA

1. Overview

TablePlus is an enterprise Autodesk Revit add-in designed as a comprehensive tabular and spreadsheet management suite. It allows BIM managers, architects, and engineers to import Microsoft Excel spreadsheets (.xlsx, .xlsm, .csv) directly into Autodesk Revit as native vector Drafting Views or Legend Views without quality degradation.

Unlike rasterized screen captures or bitmap imports, TablePlus generates true parametric vector elements: crisp detail lines for borders, filled regions for cell background fills, and native Text Note elements configured with matched fonts, weights, colors, and alignments. All generated tables are stamped with an Extensible Storage schema for future synchronization and lifecycle management.

2. Requirements and Compatibility

Compatibility: Supported on 64-bit Windows across Autodesk Revit 2024, 2025, 2026, and 2027.
  • Platform: .NET Framework 4.8 (Revit 2024) / .NET 8.0 (Revit 2025, 2026, 2027).
  • Host Application: Autodesk Revit 2024, 2025, 2026, 2027 (Win64).
  • Office Dependency: None. TablePlus operates via managed OpenXML libraries (ClosedXML) and does not require Microsoft Office or Excel to be installed on the machine.

3. Installation & Uninstallation

The installer that ran when you downloaded this plug-in from the Autodesk App Store has already installed the plug-in. You may need to restart the Autodesk product to activate the plug-in.

To uninstall this plug-in, exit the Autodesk product if you are currently running it, simply rerun the installer by downloading it again from the Autodesk App Store, and select the 'Uninstall' button, or you can uninstall it from 'Control Panel\Programs\Programs and Features' (Windows 10/11), just as you would uninstall any other application from your system.

4. Ribbon Panel Integration

By default, in accordance with Autodesk App Store single-command guidelines, TablePlus integrates into Revit's ribbon under the DBDev Tools tab (or the native Add-Ins tab):

5. Key Features & Comprehensive Usage Guide

5.1. Excel Vector Geometry Engine

When an Excel workbook is imported, TablePlus calculates physical dimensions based on column widths and row heights converted into internal Revit imperial units (feet):

  • Cell Borders: Generated as clean, closed Revit detail lines. Multiple line weights, styles, and edge topologies (thin, medium, thick, double, dashed) are faithfully mapped.
  • Cell Background Shading: Cells with background fill colors are rendered using solid FilledRegion elements with matched RGB color types.
  • Merged Cells: Merged ranges are unified into combined boundary polygons with centered text note alignment across the full merged span.
  • Typographic Fidelity: Text elements inherit the source font family, font size, bold, italic, underline, font color, horizontal alignment (Left, Center, Right), and vertical alignment (Top, Middle, Bottom).

5.2. Target View Flexibility

Users can import tables into:

  • New Drafting View: Creates a dedicated Drafting View at 1:1 scale (e.g. Table_GeneralNotes), ideal for placing on multiple sheets.
  • Existing Drafting View: Inserts or replaces tabular content within an active drafting view.
  • Legend View: Creates a Legend View allowing tabular graphic standards to be placed simultaneously across multiple documentation sheets.

5.3. Extensible Storage Metadata Tracking

Every view created by TablePlus is tagged with an invisible Extensible Storage schema (GUID: E3B21D40-6C9A-4E2F-8A11-92D0543B7A1C) recording:

  • Source workbook file path.
  • Worksheet name and imported cell range address (e.g., A1:G35).
  • Last import UTC timestamp.
  • Active update behavior configuration.

5.4. Modern Card-Based User Interface

The import dialog features the FilterPlus modern card-based theme with live validation, file browsing, automatic sheet discovery, range preview, and scale/view type selectors.
