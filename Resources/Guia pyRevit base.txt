## 1. Introducción a WPF en pyRevit
[cite_start]WPF (Windows Presentation Foundation) es un framework de interfaz de usuario moderno creado por Microsoft para construir aplicaciones de escritorio y formularios UI[cite: 179, 180]. En el ecosistema de pyRevit, WPF es el estándar de oro para las interfaces de usuario.

## 2. El Patrón de Diseño MVVM
[cite_start]MVVM (Model-View-ViewModel) es un patrón de arquitectura de software crucial para separar la interfaz gráfica (Frontend) de la lógica de negocio (Backend)[cite: 185, 186]. Comprender esto es vital para desarrollos de nivel Senior.

[cite_start]El patrón consta de tres componentes[cite: 187]:
1.  [cite_start]**Model (El Modelo):** Representa los datos y la lógica de la aplicación[cite: 187]. 2.  [cite_start]**View (La Vista):** Es la capa frontal de la interfaz, escrita en XAML[cite: 187]. [cite_start]Muestra los datos y permite al usuario interactuar con ellos[cite: 187, 189].
3.  [cite_start]**ViewModel (El Modelo de Vista):** Actúa como un "traductor" entre el *Model* y la *View*[cite: 188]. [cite_start]Toma los datos crudos de la API de Revit (Model) y los envuelve en clases compatibles para que se muestren correctamente en la interfaz XAML (View)[cite: 188, 190].

# Manejo Eficiente de Datos en la API de Revit

## 1. Revit como Base de Datos
Para interactuar con el modelo BIM de manera programática, debes entender que un archivo de Revit es fundamentalmente una base de datos estructurada.
* Todo en Revit (muros, líneas, vistas, configuraciones) es un `Element`.
* El acceso a esta base de datos se realiza a través de la clase `Document` (generalmente accesible vía `__revit__.ActiveUIDocument.Document` en pyRevit).

## 2. El Recolector: FilteredElementCollector
La única forma de extraer elementos de la base de datos de Revit es utilizando la clase `FilteredElementCollector`. Iterar sobre toda la base de datos sin filtros y comprobar condiciones usando sentencias `if` nativas de Python es una práctica prohibida por su extrema ineficiencia.

### Regla de Rendimiento (Optimización O(n)):
**Pasa la carga de trabajo a la API de Revit (C++), no a Python.** Usa los filtros nativos de la API antes de convertir los resultados en listas o iterables de Python.

## 3. Filtros Rápidos vs. Filtros Lentos
La API de Revit clasifica sus filtros de búsqueda en dos categorías. Siempre debes priorizar los filtros rápidos.

### Filtros Rápidos (Quick Filters)
Operan a nivel de los metadatos del elemento en memoria, sin necesidad de expandir completamente el objeto, haciéndolos extremadamente rápidos.
* `OfCategory(BuiltInCategory)`: Filtra por categoría (ej. OST_Walls, OST_Doors).
* `OfClass(Type)`: Filtra por la clase del objeto en la API (ej. `Wall`, `FamilyInstance`).
* `ElementIsElementTypeFilter(bool)`: Separa Tipos (Types) de Ejemplares (Instances). La API provee atajos convenientes para esto:
    * `.WhereElementIsNotElementType()` -> Obtiene ejemplares.
    * `.WhereElementIsElementType()` -> Obtiene tipos.

### Filtros Lentos (Slow Filters)
Requieren que Revit expanda completamente la geometría o los parámetros del elemento en memoria para evaluarlos. Úsalos **solo después** de haber aplicado al menos un filtro rápido.
* `ElementParameterFilter`: Busca elementos por el valor de un parámetro específico.
* Filtros espaciales y de intersección de geometría (`BoundingBoxIntersectsFilter`, `ElementIntersectsElementFilter`).

## 4. Plantillas de Código (Snippets) Eficientes

### A. Coleccionar todos los ejemplares de una categoría (Ej: Muros)
```python
from Autodesk.Revit.DB import FilteredElementCollector, BuiltInCategory

# 1. Instanciar el colector
# 2. Aplicar filtro rápido de categoría
# 3. Excluir Tipos (obtener solo ejemplares)
# 4. Convertir a elementos iterables
walls = (FilteredElementCollector(doc)
         .OfCategory(BuiltInCategory.OST_Walls)
         .WhereElementIsNotElementType()
         .ToElements())

```

### B. Coleccionar Tipos de Familia (Ej: Tipos de Muro)

```python
from Autodesk.Revit.DB import FilteredElementCollector, WallType

# Uso del filtro rápido OfClass
wall_types = (FilteredElementCollector(doc)
              .OfClass(WallType)
              .ToElements())

```

### C. Buscar Vistas en el Proyecto (Evitando bucles 'for' ineficientes)

```python
from Autodesk.Revit.DB import FilteredElementCollector, BuiltInCategory, View

# Obtener todas las vistas del proyecto (Tipos y Ejemplares)
views = (FilteredElementCollector(doc)
         .OfCategory(BuiltInCategory.OST_Views)
         .OfClass(View)
         .ToElements())

```

## 5. Manejo de Parámetros

Una vez obtenidos los elementos, acceder a sus datos implica consultar sus `Parameters`.

* Usa `element.LookupParameter("NombreDelParametro")` con precaución, ya que falla si hay parámetros duplicados (compartidos vs de proyecto) o depende del idioma.
* **Práctica Senior:** Prefiere el uso de `element.get_Parameter(BuiltInParameter.NOMBRE_DEL_PARAMETRO)` siempre que sea posible. Es universal, a prueba de idiomas y computacionalmente más robusto.

# Actualizaciones y Obsolescencias en la API de Revit 2026

## 1. Introducción
[cite_start]Revit 2026 trae nuevas características y cambios que afectan el funcionamiento de la API, por lo que es crucial conocer qué ha sido eliminado, qué ha cambiado y qué nuevas funciones están disponibles para que los scripts continúen funcionando sin problemas[cite: 244]. Como desarrollador Senior, debes verificar siempre la compatibilidad de los métodos según la versión de Revit en la que operará el script.

## 2. Cambios Críticos y ElementId
El manejo de los identificadores de elementos ha sufrido modificaciones importantes de tipo de datos en las versiones recientes, consolidándose en 2026:
* [cite_start]**ElementId a 64 bits:** El constructor de `Autodesk.Revit.DB.ElementId` ha sido modificado internamente para utilizar enteros de 64 bits (`integer 64`) en lugar de 32 bits (`integer 32`)[cite: 248, 249].
* [cite_start]**Obtención del valor numérico:** La antigua propiedad `IntegerValue` ha sido completamente eliminada de la API[cite: 249]. [cite_start]Ahora se debe utilizar estrictamente la propiedad `Value` en su lugar[cite: 250].

## 3. Eliminaciones y Sustituciones Frecuentes
Muchos métodos y propiedades comunes han sido reemplazados o renombrados. Al programar, asegúrate de utilizar las versiones actuales:
* [cite_start]**Slab Shape Editor (Suelos y Cubiertas):** Para las clases `Floor` y `RoofBase`, la propiedad `SlabShapeEditor` ha sido eliminada; en su lugar, se debe llamar al método `GetSlabShapeEditor()`[cite: 251].
* [cite_start]**Dibujo en Slab Shape Editor:** Los métodos `DrawPoint` y `DrawSplitLine` han sido reemplazados por `AddPoint` y `AddSplitLine` respectivamente[cite: 257].
* [cite_start]**Viscosidad en MEP:** Propiedades como la viscosidad del aire y conductos han sido renombradas para incluir la palabra "Dynamic" (ej. `DynamicViscosity`)[cite: 251, 252].
* [cite_start]**Fases:** La propiedad `NumberofPhases` cambió su nombre a `PhasesNumber`[cite: 252].
* [cite_start]**Matrices (Arrays):** Métodos relacionados con arreglos radiales y lineales fueron removidos y reemplazados por controles como `IsValidNumberOfMembers`[cite: 257].
* [cite_start]**Curvas:** El método `IsCurveLoopValid` fue removido y reemplazado por `IsOuterControlValid`[cite: 257, 258].
* [cite_start]**Importación PDF:** El método `IsPdfImportAvailable` fue eliminado ya que siempre retornaba verdadero[cite: 253].

## 4. Cambios Estructurales y de Geometría
[cite_start]La API para estructuras, especialmente las armaduras (Rebars), ha recibido modificaciones masivas en Revit 2026[cite: 268, 269].
* [cite_start]**Estructuras Compuestas (Compound Structures):** Las capas del núcleo (*core layers*) ya no son requeridas estrictamente, lo que facilita la creación programática de muros y cerramientos[cite: 265, 266].
* [cite_start]**Posicionamiento de Vistas:** Se introdujo la nueva clase `ViewPosition` para manejar el posicionamiento automatizado de vistas dentro de los planos (*sheets*)[cite: 264].
* [cite_start]**Toposolids:** Se añadieron nuevos métodos como `CreateSubdivision` y herramientas de estabilidad de cortes (`CutVoidStability`)[cite: 274].
* [cite_start]**CEF:** El Chromium Embedded Framework (CEF) fue removido de la API[cite: 260].
* [cite_start]**Eventos de Cierre:** Los eventos `DocumentClosing` y `DocumentClosed` ya no serán invocados si Revit se cierra por corrupción o cancelación del proceso[cite: 266, 267].

## 5. Advertencia sobre la Documentación Oficial 2026
[cite_start]Al buscar referencias de clases en la documentación oficial de la API de Revit 2026, notarás que mucha información vital, como descripciones detalladas, comentarios (`remarks`) y ejemplos de código, ha sido omitida[cite: 283, 284]. 
* [cite_start]**Estrategia de Depuración:** Si necesitas comprender en profundidad una clase o método en 2026, es altamente recomendable consultar la documentación de la versión 2025 para obtener contexto y ejemplos adicionales[cite: 283, 284].

# Despliegue, Control de Versiones y Distribución Corporativa

## 1. Importancia del Control de Versiones
El desarrollo profesional exige proteger el código fuente. [cite_start]Alojar y respaldar tus extensiones de pyRevit en repositorios Git (como GitHub, GitLab o Azure DevOps) antes de que sea "demasiado tarde" es una práctica obligatoria[cite: 17]. Git permite rastrear cambios, colaborar con otros desarrolladores de la empresa y revertir el código si una actualización rompe un flujo de trabajo.

## 2. Preparación del Repositorio
Al preparar tu herramienta para distribución:
* **Estructura limpia:** Asegúrate de que el repositorio contenga directamente la carpeta `.extension` (ej. `MiEmpresa.extension`).
* [cite_start]**Ignorar archivos innecesarios:** Configura un archivo `.gitignore` para excluir archivos temporales, cachés de Python (`.pyc`) o elementos autogenerados durante las pruebas[cite: 68].
* [cite_start]**Documentación:** Incluye siempre un archivo `README.md` en la raíz del repositorio que explique cómo utilizar la extensión y sus dependencias[cite: 131, 132].

## 3. Métodos de Instalación y Despliegue
Existen dos formas principales de instalar extensiones de pyRevit en los equipos de los usuarios finales:

### A. Instalación Manual (Recomendada para usuarios básicos o pruebas locales)
El método más directo consiste en agregar la extensión en la carpeta de itinerancia (Roaming) de Windows del usuario. 
* [cite_start]Navega a la ruta introduciendo `%appdata%` en la barra de direcciones del explorador de archivos[cite: 134].
* [cite_start]Copia el contenido de la extensión (la carpeta `.extension` completa) en la ruta de extensiones de pyRevit (usualmente `%appdata%\pyRevit\Extensions`)[cite: 134].
* [cite_start]Recarga pyRevit en la interfaz de Revit para que los cambios surtan efecto[cite: 133]. [cite_start]Este enfoque es útil para configuraciones rápidas[cite: 134, 135].

### B. Instalación Automatizada vía pyRevit CLI (Recomendada para empresas)
[cite_start]Para evitar instalaciones manuales y facilitar actualizaciones corporativas, se debe utilizar la interfaz de línea de comandos (CLI) de pyRevit[cite: 132]. Este método puede integrarse en scripts de despliegue de TI (ej. archivos `.bat` o PowerShell).

**Flujo de comandos:**
1. [cite_start]Abre la terminal (`cmd`)[cite: 133].
2. [cite_start]Ejecuta el comando de instalación apuntando al repositorio Git de la extensión[cite: 133]. 

*Sintaxis de ejemplo:*
```cmd
pyrevit extend ui NombreExtension [https://github.com/Usuario/Repositorio.git](https://github.com/Usuario/Repositorio.git) --dest="C:\Ruta\De\Instalacion" --branch=main

```

*(Nota: Reemplaza la URL y las rutas por las de tu servidor corporativo o repositorio. Esto descargará la herramienta e instruirá a pyRevit para que la cargue)*.
3. Si Revit ya estaba abierto, utiliza el botón "Reload" de pyRevit para que aparezca la nueva pestaña.

## 4. Gestión de Actualizaciones

* Al utilizar el método CLI vinculado a un repositorio Git, pyRevit puede gestionar las actualizaciones de las extensiones de manera integrada.


* **Entornos separados:** Mantén siempre una rama `main` (producción) y ramas de desarrollo (`dev`). Los usuarios finales solo deben apuntar a la rama de producción para garantizar que las herramientas sean estables.
